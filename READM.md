# Pomodoro Timer

Pomodoro Timer is a PixelMug MPS app for focused work sessions and timed breaks. The WebApp lets users configure focus duration, break lengths, cycle count, and alert sounds, then sync those settings to the PixelMug device.

After syncing, the timer runs locally on PixelMug. The device shows the current countdown and supports simple physical controls: tap to start or pause/resume, and use the device interaction flow to stop or return to ready state. The WebApp is mainly used as a setup and sync panel, while the device handles the actual timing experience.

## Features

- Configure focus minutes, short breaks, long breaks, and cycle count.
- Enable or disable alert sounds.
- Choose between Classic and Gentle sound themes.
- Sync settings to PixelMug without starting automatically.
- Start the timer from the device with a single tap.
